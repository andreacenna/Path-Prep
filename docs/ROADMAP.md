# Roadmap

Done in v0.1: all 7 build phases at a first-version level — foundation, learning engine, full curriculum content (149 lessons), interview academy, daily briefing pipeline, tests and deployment.

Next:
1. **Content depth** — split the longest deep lessons; add second-level lessons (e.g. IFRS 3 step acquisitions, pushdown accounting, NAV loans, convertible accounting, bank capital, insurer valuation), more spreadsheet grids, more Italian market examples (Euronext Milan, Consob/TUF), additional case studies (Siemens/Alstom, Dell/EMC, TXU, Intesa/UBI, UniCredit/BPM-type situations once facts are verified).
2. **Content review cadence** — re-check standards/thresholds every 6 months (`reviewed` dates); add a "report an error" button that pre-fills a GitHub issue.
3. **On-device transcription (optional)** — Whisper via transformers.js (Apache-2.0) as a private, offline alternative to the Web Speech API (≈40–75 MB model download, opt-in).
4. **Formula-capable modelling sandbox** — small in-browser spreadsheet with formulas for DCF/LBO builds.
5. **Adaptive scheduling across content** — schedule *questions* (not just flashcards) with FSRS; difficulty targeting per topic.
6. **Optional sync** — encrypted backup to a user-owned location (file/Drive) without a server.
7. **News** — add more free official sources (Banca d'Italia, Consob, European Commission competition), Italian-language feeds, and per-item concept quizzes with stricter rules.
